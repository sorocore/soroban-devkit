# soroban-devkit

The definitive toolkit for Soroban developers.

This repository is a monorepo scaffold and architecture for building a full-featured, community-driven toolkit for working with Soroban smart contracts and Stellar integration.

Status: scaffolded — core architecture only. Implementations are placeholders and TODOs.

Getting started

1. Install pnpm: https://pnpm.io/
2. From repo root: pnpm install
3. Run build: pnpm -w build
